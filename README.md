# altinemlakgop-medya
Altın Emlak Gaziösmanpaşa sosyal medya görselleri

## Bulut çalışma düzeni
Zamanlanmış görevler bilgisayara bağlı olmadan çalışır: şablonlar `_sablon/` içinde, kurulum `FONT_KEY=... bash _sablon/kur.sh`.
Yazı tipleri lisans gereği şifreli tutulur (`_sablon/fonts.tgz.enc`). Üretilen görseller ilgili klasöre (konut-satis/, kfe/, kira/, blog/, portfoy/) yüklenir; bir ayın klasörü varsa o ay yapılmış sayılır.
